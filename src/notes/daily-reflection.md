Day 1 – Daily Learning Reflection
1. Values and data types
I learned that JavaScript uses different data types to store information.
- String: stores text.
- Number: stores numerical values.
- Boolean: stores true or false.
- Undefined: represents a variable that has been declared but not assigned a value.
- Null: represents an intentional absence of a value.
2. Variables
I learned the difference between const and let.
- const is used when a variable should not be reassigned.
- let is used when a variable needs to change.
3. Operators and calculations
I practised addition, subtraction, multiplication, division and the remainder operator.

I used these operators to calculate prices, quantities, tax and discounts.
4. Conditions
I used if, else if and else to make decisions in JavaScript.

For example, I created a grading function that returns a grade depending on a student's score.
5. Loops
I used a for...of loop to go through a list of prices and calculate their total.

I also used a for loop to implement the FizzBuzz challenge.
6. Functions
I learned that a function is a reusable block of code that performs a particular task.

I practised creating functions with parameters and return values, including receipt calculation functions.
7. Debugging
I learned to use the browser developer console to view output, identify errors and check whether my code produces the expected results.
8. Required challenges
I practised the four required challenges:
1. Converting minutes into hours and remaining minutes.
2. Assigning grade labels based on scores.
3. Implementing the FizzBuzz challenge.
4. Calculating discounts before applying tax to a shopping cart.
Conclusion
Day 1 helped me understand the basic building blocks of JavaScript. I practised working with values, variables, operators, conditions, loops and functions. I also learned how to test my code and identify errors.
