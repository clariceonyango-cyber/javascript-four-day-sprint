
# JavaScript Four-Day Sprint

## Project Overview

This repository contains my practical work and learning activities from the JavaScript Four-Day Sprint. It demonstrates my progress in JavaScript programming, problem-solving, asynchronous programming, Git, and GitHub.

The main project is a **Focus Board**, a task management application that allows users to organise and manage their daily activities.

## Learning Objectives

- Understand JavaScript fundamentals.
- Practise variables, functions, arrays, and objects.
- Work with DOM manipulation and events.
- Understand promises, async/await, and Fetch API.
- Use local storage to save tasks.
- Practise Git branches, commits, and pull requests.
- Build and test a functional JavaScript application.

## Day 1 – JavaScript Fundamentals

Practised JavaScript basics, variables, data types, functions, and problem-solving exercises.

## Day 2 – JavaScript Logic and Functions

Worked with arrays, objects, functions, and practical JavaScript exercises.

## Day 3 – DOM Manipulation and Application Features

Practised working with the DOM, events, task management, searching, and filtering.

## Day 4 – Asynchronous JavaScript

Practised:
- Promises and Promise states.
- Async/await.
- Fetch API.
- HTTP response checking.
- JSON parsing and validation.
- Loading, success, and error states.
- Retry functionality.
- Promise.all for multiple requests.
- AbortController for cancelling requests.
- Handling empty and invalid responses.

## Focus Board Application

The Focus Board is a task management application developed using HTML, CSS, and JavaScript.

### Features

- Add new tasks.
- Complete and undo tasks.
- Delete tasks.
- Search and filter tasks.
- Save tasks using local storage.
- Export tasks as JSON.
- Import tasks from JSON files.
- Load suggestions from an external API.
- Display loading and error messages.
- Retry failed suggestion requests.
- Continue managing saved tasks offline.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Use the Focus Board to add, complete, search, and manage tasks.
5. Open `src/day3-practice.html` for Day 3 practice.
6. Open `src/day4-practice.html` for Day 4 practice.
