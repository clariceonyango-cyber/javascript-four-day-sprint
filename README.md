# JavaScript Four-Day Sprint – Focus Board

## Project Overview
My Focus Board is a task management application built using HTML, CSS and JavaScript.

## Features
- Add tasks with priority levels.
- Complete and undo tasks.
- Edit task titles.
- Delete and restore tasks.
- Search tasks by title.
- Filter tasks by status.
- Track task progress.
- Save tasks using localStorage.
- Load online task suggestions.

## Technologies
- HTML5
- CSS3
- JavaScript ES Modules
- Browser localStorage
- Fetch API

## How to Run
1. Download or clone this repository.
2. Open the project in Visual Studio Code.
3. Open index.html using Live Server.
4. Add and manage your tasks.

## Project Structure
- index.html
- styles.css
- src/app.js
- src/task.js
- src/storage.js
- src/api.js
